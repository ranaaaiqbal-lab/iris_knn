         Iris Classification using K-Nearest Neighbors (KNN) with Streamlit
📌 Project Overview
This project demonstrates a simple Machine Learning classification app using the famous Machine Learning Iris Dataset and the K-Nearest Neighbors (KNN) algorithm.
The frontend interface is built using Streamlit, allowing users to interactively input flower measurements and predict the Iris species.

🚀 Features
Interactive web interface using Streamlit
Train and test a KNN classifier
Predict Iris flower species based on user input
Simple and beginner-friendly ML project
Real-time prediction display

🧠 Technologies Used
Python
Streamlit
Scikit-learn
Pandas
NumPy
Matplotlib (optional for visualization)



📂 Dataset
The project uses the built-in Iris Dataset from Scikit-learn, which contains:


Sepal Length
Sepal Width
Petal Length
Petal Width
Target Classes:
Iris Setosa
Iris Versicolor
Iris Virginica
